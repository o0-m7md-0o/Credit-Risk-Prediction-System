# 💳 Credit Risk Prediction System

## 📌 Project Overview
This project is an AI-powered system designed to predict credit risk. By analyzing historical customer data, the model identifies potential default risks, helping financial institutions make data-driven loan approval decisions.

## 🎯 Objectives
- **Risk Assessment:** Classify customers into High-Risk and Low-Risk categories.
- **Data Integrity:** Clean and preprocess financial data, handling outliers and missing values.
- **Automation:** Streamline the credit evaluation process using Machine Learning.

## 🛠 Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Scikit-learn, LightGBM, Matplotlib, Seaborn.

## ⚙️ Key Features
- **Exploratory Data Analysis (EDA):** Deep dive into correlations between income, age, and loan default.
- **Handling Imbalanced Data:** Implementation of techniques to manage skewed datasets.
- **Advanced Modeling:** Used **LightGBM** for high-efficiency and accurate classification.

## 📊 Results
The model achieved high performance across key metrics (Accuracy, Precision, and Recall), demonstrating its reliability in a production-like environment.
